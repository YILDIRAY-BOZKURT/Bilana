BILANA

Sample data

A backup file with fictional buildings, units and payments for trying Bilana.

Backup filebilana-sample.json

How to load it

  1. Open this page in Safari on the iPhone and tap the file above. It is saved to Files › Downloads.
  2. In Bilana, go to Help › Data Backup › Restore and choose bilana-sample.json.
  3. Confirm with Replace. Restoring replaces the data currently in the app.

The file contains 6 buildings with August–October 2026 dues and utilities, expenses and installment plans. All names and phone numbers (+1 555) are fictional.
